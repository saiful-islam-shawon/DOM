সব Event Handlers এর তালিকা

🖱️ Mouse Events

js

onclick        // click করলে
ondblclick     // double click করলে
onmousedown    // mouse button চাপলে
onmouseup      // mouse button ছাড়লে
onmouseover    // mouse element এর উপর আসলে
onmouseout     // mouse element থেকে সরে গেলে
onmousemove    // mouse নড়লে

⌨️ Keyboard Events

js

onkeydown      // key চাপলে
onkeyup        // key ছাড়লে
onkeypress     // key চেপে ধরলে (deprecated)

📝 Form Events

js

oninput        // typing এর সাথে সাথে
onchange       // focus সরে গেলে
onsubmit       // form submit করলে
onfocus        // input এ click করলে
onblur         // input থেকে বের হলে
onreset        // form reset করলে
onselect       // text select করলে

🌐 Window/Document Events

js

onload         // page load হলে
onunload       // page বন্ধ হলে
onresize       // window resize করলে
onscroll       // scroll করলে
onbeforeunload // page ছাড়ার আগে

📱 Touch Events (Mobile)

js

ontouchstart   // touch শুরু হলে
ontouchend     // touch শেষ হলে
ontouchmove    // touch করে নাড়লে

🎬 Media Events

js

onplay         // video/audio play হলে
onpause        // pause করলে
onended        // শেষ হলে
onvolumechange // volume বদলালে

🖱️ Drag Events

js

ondrag         // drag করার সময়
ondragstart    // drag শুরু হলে
ondragend      // drag শেষ হলে
ondrop         // drop করলে

সহজ Example সব দিয়ে:

html

<input 
  onfocus="console.log('focused')"
  onblur="console.log('left')"
  oninput="console.log('typing')"
  onchange="console.log('changed')"
>

<button 
  onclick="console.log('clicked')"
  onmouseover="console.log('hovering')"
>
  Click Me
</button>

<script>
  window.onload = () => console.log("page loaded");
  window.onscroll = () => console.log("scrolling");
  window.onresize = () => console.log("resized");
</script>

মনে রাখার উপায়:

on + [কী হচ্ছে] = event handler

on + click     = onclick
on + input     = oninput
on + scroll    = onscroll
on + load      = onload
